# Transfer Coach · Final Prototype

A clickable, single-file prototype of **Transfer Coach**, a mobile app that helps commuters make train-to-bus transfers with less uncertainty and stress. Built for UTS Advanced Interaction Design (31777 | 32509), team Loop Design.

**Open the demo:** open `index.html` in a browser (it looks best on a phone or a narrow window).

## What it shows
- Trip set-up with an event time ("Arriving for · Concert 10:30"), a sliding preference control and mode chips
- A journey rail on every in-trip screen showing the current stage and minutes before the event
- A live status card (Take it easy / Walk a bit faster / RUN!)
- Station guidance with walking times for each exit
- Delays shown with the new arrival time and whether the delay is included
- Route options led by arrival time; the Start button names the selected route
- Recovery flows for a missed train, a missed bus and a wrong stop

## Demo scenarios
Open the **Alerts** tab and tap one of the three scenarios (running late, bus delayed, train delayed).

All data in the prototype is demo data for one sample trip.
